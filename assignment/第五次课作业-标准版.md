# 三轮迭代检索
## 1.宽度检索 
关键词 “Sequential recommendation” \
使用平台 *dblp*，*google scholar* \
检索结果，dblp超过2k条检索记录，其中甚至包含非计算机领域的相关研究；google scholar检索到3000000条记录，根据被引次数，初步选Self-attentive sequential recommendation，Time Interval Aware Self-Attention for Sequential Recommendation，BERT4Rec: Sequential recommendation with bidirectional encoder representations from transformer，Personalized top-n sequential recommendation via convolutional sequence embedding，等文章作为序列推荐方向经典基础文章
## 2.深度检索
关键词 根据泛读论文的结果，大致得出需要使用更多的用户行为数据以及更高效的计算方式，所以确定关键词为“Efficiency”，“LightWeight”，“Multi-Behaviour”,"heterogeneous interaction"\
使用Semantic scholar查找引用了该文献的论文，找到3928个结果，使用关键词"efficient" OR "lightweight"没有找到相关工作，使用关键词“Multi-Behaviour”找到61篇相关工作。\
两两组合关键词进行检索，选择其中被引数较高且在检索结果中重合的文章Graph Meta Network for Multi-Behavior Recommendation，Multi-Behavior Sequential Recommendation  
with Temporal Graph Transformer，Multi-Behavior Hypergraph-Enhanced Transformer  
for Sequential Recommendation
## 3.作者文献检索
在第二轮检索结果中，发现选出来的几篇都是同一个课题组的论文，所以在这论检索中选择查看该课题组的相关论文
检索工具 Semantic Scholar
在该作者的论文中进行二次检索，关键词为Multi-Behavior
从其技术路线上来看，20年首次研究Multi-Behavior，并提出MATN(Memory-Augmented Transformer Networks)用于该研究。21年转向使用图神经网络+知识增强，其中影响力最大的是SIGIR(Graph Meta Network for Multi-Behavior Recommendation)，提出使用元学习范式引入多行为推荐，让模型能自动挖掘“类型相关的行为表示”。22年对比学习/自监督学习成为主线，兼顾序列建模。23年之后多行为这个概念不再是主线工作。
