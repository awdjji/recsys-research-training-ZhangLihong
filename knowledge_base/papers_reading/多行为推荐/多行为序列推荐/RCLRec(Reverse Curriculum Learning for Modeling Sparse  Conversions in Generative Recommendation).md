长短周期中的近期偏好建模：购买事件出现之前通常会出现一个内聚的相关物品簇，即长历史交互中的一小部分行为往往构成一个关键的决策子序列。使用RCPM模块从历史中逆向选取 k 个关键中间行为以构成课程前缀。该前缀与目标转化 token 一同注入解码器，在稀疏转化信号下提供额外的、实例特定的中间监督，并使模型聚焦于用户的关键决策过程。
课程质量感知损失（curriculum quality-aware loss），促使被选取的子序列对转化更具信息量。
计算选择topk的分数时会先计算一下用户表征和购买通用embedding的一个query，再用这个q来和历史行为计算得分，那有没有可能购买行为会比关键辅助行为更容易获得更高的分数。
- **在选择器里显式解耦行为类型**：对不同行为类型分别选 top-k 再合并，或加行为类型的配额，避免被某一类垄断。
- **用 item 作 query 的变体**：query 里放入候选或目标行为 item，才能让选择依赖于"与这次购买相关"，而不只是一个用户级先验。这也与你的第一阶段结果更一致（你测到的显著信号是目标对齐，而论文选择器没有直接使用目标 item）。
