#### 1.提出了什么问题：
- 多行为交互中存在复杂的混淆行为交互倾向，即流行度和与特定行为偏差相互交织。
- 异质行为模式需要动态聚合，因为辅助行为对于特定的用户-物品对在信息量上存在差异。
- 显著的语义鸿沟和偏差分布妨碍了有效的跨行为特征合并。
#### 2.解决方法：
- 因果偏好评估用于对表征去偏
- 基于 MoE 的自适应聚合，动态融合异质辅助行为信息
- 偏差感知的对比学习
#### 3.任务定义与符号：
- 数据：K 种行为类型，行为之间有先后依赖（如 view → cart → purchase）。
- 目标行为 $K_t$（即purchase），前面的行为 {1,…,$K_{t−1}$} 是辅助行为。
- 模型无关的设定：以骨干模型学到的行为特定嵌入 $e_{u,k}、e_{i,k} ∈ R^d$ 作为输入。
- 形式化（第3节"Problem Formulation"）：输入是交互图 G、多行为偏置集合${b_{u,k}, b_{i,k}}$和骨干嵌入；目标是学习增强函数 f(·)，输出目标行为的预测分数 $ŷ_{ui}$（式1）。
#### 4.整体框架：
交互数据一方面送入骨干，得到各行为下的用户、物品嵌入；另一方面统计出偏置$b_u、b_i$和 Jaccard 相似度。嵌入和偏置一路相乘得到 $S_{base}$，一路 concat 后经 MoE 门控；二者与 Jaccard 一起合成 $S_{final}$，用于主训练损失。同时，骨干给出的各行为嵌入也送入对比学习模块，用同一用户（物品）的跨行为嵌入作正样本、同批次其他用户（物品）作负样本，计算带自适应温度的 InfoNCE。两部分损失共同训练骨干和各模块。推理时只用目标行为下用户与物品嵌入的内积。
*公式4用的是$f_k (u, i) · g_k (b_{u,k},b_{i,k})$ 标量相乘，而Figure1中计算S_{base}用的是$\otimes$,即逐元素相乘*
*在Adaptive Aggregation module中$S_{base}$貌似只是一个标量，但是在Figure1中却是一个向量，代码得到的结果是一个标量*
#### 5.各模块的关键内容：
因果偏好估计：
- 图2中的变量：U、I（用户、物品特征），M（中介行为，即初始交互），Y（行为结果），B_u、B_i（用户、物品固有的多行为偏置，隐混杂变量）。
- 后门路径示例：U ← B_u → M → Y。
- 后门调整公式（式2）与附录A的推导（14a–14e）。
- 偏置代理：式3，用相对行为频率；作者把它解释为"广义行为转化率"，并说明相比成对转化率的 O(K²) 复杂度更高效。
- 参数化：式4$（S_{base} = f_k · g_k）、式5（f_j · S_{contrib}）$。
自适应聚合模块：
- 最终训练分数：$S_{final} = S_{base} · (1 + C)（式6、7）$。
- Con(k→$K_t$) 由两路加权：结构门控（Jaccard 相似度，式8）和语义门控（MoE，式9），权重 $λ_J、λ_M$ 可学习。
- 论文给出的目标是"最大化正迁移、抑制负迁移"。
偏置感知的对比学习模块：
- 把每种行为看作一个"视图"；同一用户（物品）在不同行为视图下的嵌入为正样本对，同批次其他用户（物品）为负样本对。
- InfoNCE 损失（式11）。
- 自适应温度 $τ_{u,k_j} = τ₀·(1 − α·b_{u,k_j}$)（式10），物品侧类似。
- 总损失：用户侧与物品侧求和，β 平衡（式12）。
#### 6.实验设置：
- 数据集（表1）：Tmall、Jdata、Taobao，以及各数据集的用户数、物品数和各行为交互数；预处理与文献 [4, 43] 一致。
- 基线共四类：单行为、多行为、集成因果的多行为（CVID、CMSR）、可插拔因果方法（SNIPS、CausE、Multi-IPW、DCCL）。
- 接入 MCLMR 的骨干：LightGCN、HEC-GCN、CRGCN、BCIPM。
- 指标：HR@K、NDCG@K，K = 10 和 50，预测针对目标行为 buy。
- 实现：PyTorch，RTX 4090，Adam，嵌入维度 64，使用各骨干的最优设置。
- 超参搜索空间（附录B）：$γ_u、γ_i$ ∈ {0.01, 0.1, 0.5, 1.0}；MoE 隐藏维度 ∈ {32, 64, 128}；τ 与 $λ_{CL}$ 另行调节。
