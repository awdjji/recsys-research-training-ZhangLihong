# Latex
在Obsidian中，使用$来前后包裹Latex数学公式\
\times在Latex语法中用来输出$\times$ \
\mathbb{}用来表示黑板粗体如$\mathbb{R}$ \
\hat{}用来加帽子符号$\hat{H}$ \
\widehat{}用来加更宽的帽子符号$\widehat{HH}$ \
\tilde{}用来加波浪号$\tilde{H}$ \
\bar{}用来加横线$\bar{H}$ \
\frac{a}{b}是分式$\frac{a}{b}$ \
\dfrac{a}{b}表示加宽分式$\frac{a}{b}$ \
\tfrac{a}{b}是强制小尺寸分式$\tfrac{a}{b}$ \
\sqrt{x}表示平方根$\sqrt{x}$
\sqrt[n]{x}表示n次方根$\sqrt[n]{x}$
