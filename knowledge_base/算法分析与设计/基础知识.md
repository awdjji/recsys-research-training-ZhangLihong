渐近上界记为O(g(n))={f(n)|存在正常数c和$n_0$使得对所有的n>=$n_0$,都有0<=f(n)<=cg(n)}
渐近下界记为Ω(g(n))={f(n)|存在正常数c和$n_0$使得对所有的n>=$n_0$,都有0<=cg(n)<=f(n)}
非紧上界记为o(g(n))={f(n)|对任意的正常数c，都存在正数$n_0$使得对所有的n>=$n_0$都有0<=f(n)<=cg(n)}
非紧下界记为w(g(n))={f(n)|对任意的正常数c，都存在正数$n_0>=0$使得对所有$n>=n_0$有:0<=cg(n)<=f(n)}
紧渐近界记号$\Theta$(g(n))={f(n)|存在正常数$c_1,c_2和n_0$使得对所有的$n>=n_0$有：$c_1g(n)<=f(n)<=c_2g(n)$}
定理1：$\Theta(g(n))=O(g(n))\cap \Omega(g(n))$
传递性：
- f(n)=$\Theta(g(n)),g(n)=\Theta(h(n))=>f(n)=\Theta(h(n))$
- f(n)=O(g(n)),g(n)=O(h(n)) => f(n)=O(h(n))
- f(n)= $\Omega(g(n))， g(n)= \Omega(h(n)) => f(n)= \Omega(h(n))$
- f(n)= o(g(n))， g(n)= o(h(n))   =>  f(n)= o(h(n))
- f(n)= $\omega(g(n))， g(n)= \omega(h(n)) => f(n)= \omega(h(n))$
反身性：
- f(n)=$\Theta(f(n))$
- f(n)=O(f(n))
- f(n)=$\Omega(f(n))$
对称性：
- f(n)=$\Theta(g(n)), g(n)=\Theta(f(n))$
互对称性：
- f(n)=O(g(n)) $\Leftrightarrow g(n)=\Omega(f(n))$
- f(n)=o(g(n))$\Leftrightarrow g(n)=\omega(f(n))$
